# Lec0 Summary

- Printing & strings: `print()` basics, quoting and escaping, and using `sep` and `end` to customize output.
- User input: collecting input with `input()` and assigning it to variables.
- String methods: trimming and formatting with `strip()`, `title()`, `capitalize()`, and splitting strings.
- f-strings & concatenation: formatting output with f-strings and concatenating strings.
- Functions & main pattern: defining functions, parameters, default arguments, returning values, and organizing code with a `main()` function.
- Return values & power operators: returning results from functions and using exponentiation (`**`) or `pow()`.
- Arithmetic & types: basic arithmetic, operator precedence, and converting input strings to numbers with `int()`; readability considerations (avoid chaining too many conversions in one line).
- Unpacking: splitting input and unpacking into multiple variables (e.g., `first, last = name.split()`).
- Comments & readability: using comments and multiline strings for notes; prefer readable, well-structured code.
